QuickScale Software Demo – README

Background

This repository provides a demonstration of the QuickScale (QS) method for estimating the F-layer critical frequency from FTI plots.
QuickScale is a simplified scaling approach designed to extract ionospheric parameters more efficiently for research and educational purposes.

Data Source

The FTI plot used in this demo originates from the Pameungpeuk Ionosonde Station (Indonesia), year 2019.
All data are provided by the Space Research Center, BRIN (National Research and Innovation Agency of Indonesia).
